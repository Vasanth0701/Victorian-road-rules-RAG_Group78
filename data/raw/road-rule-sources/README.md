# Victorian Road Rules Knowledge Base Sources

This folder contains candidate official Victorian road-rule sources identified for the Victorian Road Rules RAG Assistant.

## Categories
- Learner and probationary drivers
- Mobile phone and device rules
- Speed limits
- Alcohol and BAC
- Demerit points
- Overseas licences
- Main road rules legislation

The final set of sources to be ingested into the RAG system should be reviewed and approved by the project group.
